# 《山河未尽》普通地块皮肤制作记录

> 更新日期：2026-10-18  
> 本文件记录当前已经确认的美术方向、比赛版工作基线和后期升级项。当前重点是先完成可交付、可复用的普通地块皮肤，不把后期理想方案提前做成制作负担。

## 一、已经确认的方向

### 1. 总体视觉

- 普通地块采用“青绿山水顶面 + 赭石崖壁侧面”的设计。
- 参考传统青绿山水与《千里江山图》的综合色彩关系，但不直接复制具体画面。
- 地块应像被抬高、切开的山水画卷，而不是贴有随机纹理的游戏方块。
- 程序噪声方案已经停用。地表变化必须来自人工控制的大色块、笔触、皴擦和留白。

### 2. 高差造型

- 舍弃普通地块的圆缓坡肩。
- 普通地块一律使用平整顶面、垂直侧面和清晰阶梯高差。
- 顶面与侧面之间不依靠额外圆弧网格过渡，而依靠窄幅手绘边缘带完成颜色衔接。
- 河流跨越高差时，由瀑布、跌水、湿润崖壁等专用模块负责连续；普通地块不因此改变几何结构。

### 3. 表现与玩法分离

- 地块材质和装饰只改变表现，不参与洪水容量、路径、胜负和点击规则。
- 地块尺寸、Collider、高度等级和坐标继续由 `MapGenerator` 管理。
- 山体、河道、建筑、树木主体、棋子和状态效果继续使用独立 Prefab，不合并进普通地块纹理。
- 装饰 Prefab 默认不添加 Collider，避免拦截地块点击。

## 二、当前阶段的制作基线

为了优先完成比赛版美术交付，当前先使用一套统一、可重复使用的地面纹理，不为每个关卡绘制专属地景总图。

### 1. 顶面纹理

- 所有关卡先共用一套青绿色手绘地面纹理。
- 纹理只表现低对比度的综合色彩、宽缓笔触、淡皴擦和少量纸本质感。
- 不在循环纹理中绘制可被认出的独立大树、巨石、房屋、山峰或水潭，避免重复后形成明显图案。
- 顶面整体保持安静，给山体、河道、村庄和玩法信息留出视觉层级。
- 相邻地块使用统一的世界坐标取样，避免每格纹理从头开始造成拼砖感。
- 当前首版已经依据用户提供的青绿山水阶梯参考图生成并写入 `T_Terrain_Top_Ink_A.png`；它属于可调首版，不代表最终锁定笔触。

### 2. 侧面纹理

- 侧面使用独立的赭石崖壁纹理，不与顶面共用同一张图。
- 侧面上部颜色较深，向下逐渐变浅、变暖。
- 纹理变化以纵向冲刷、矿物色痕、淡墨裂纹为主，数量要少、尺度要大。
- 不使用密集噪点、均匀颗粒或规则横向分层。
- 后续可在同一风格下增加少量侧壁变体，但当前先完成一个基础版本。
- 当前首版已经写入 `T_Terrain_Side_Earth_A.png`，包含赭石纸色、纵向矿物痕和淡裂纹。

### 3. 顶侧边缘带

- 在侧壁最上方保留一条窄幅青赭过渡带，当前约占一级侧壁可见高度的 13%。
- 顶面青绿纹理向侧壁上沿轻微渗入，下面衔接较深的赭石色；断续深色墨线放在顶面内侧，不再画在容易被视角压扁的侧壁上沿。
- 使用手绘不规则遮罩打破笔直工程线，但不改变地块真实轮廓。
- 过渡带不能宽到像坡面；顶面墨线只负责强调真实外沿和高差。正式边线由 `T_Terrain_Edge_Stroke_A.png` 的手绘笔段遮罩控制，每条露出边缘出现数段墨线与明确空隙，不能形成连续而沉重的黑框。

### 4. 当前工作色板

下列颜色只作为与现有山体并看的调色起点，不是最终锁色值。

| 用途 | 工作色值 | 状态 |
| --- | --- | --- |
| 青绿顶面 | `#748A79` | 可继续调整 |
| 青赭边缘带 | `#91846A` | 由原坡肩色转为窄边缘过渡色 |
| 侧面上部深赭 | `#8E6F50` | 托住顶面 |
| 侧面下部浅赭 | `#C3A77B` | 避免形成沉重棕墙 |
| 暖石河岸 | `#C3B38E` | 河道配色参照，不属于普通地块主体 |

## 三、当前技术落点

### 保留并继续改造

- `TerrainTileSkin.shader`：作为正式地块皮肤 Shader 的基础。
- `T_Terrain_Top_Ink_A.png`：后续替换为人工控制的统一青绿地面纹理。
- `T_Terrain_Side_Earth_A.png`：后续替换为人工控制的赭石侧壁纹理。
- `D_普通地块_A_静地` 与 `P_普通地块_A_静地`：继续作为普通静地的定义与内容锚点。
- `TerrainArtValidation3x3.unity`：继续作为第一轮小样验证场景，但其中的坡肩实验内容需要在实施阶段移除。

### 停止继续投入

- `TerrainColorShoulder.shader`：仅保留为旧实验记录，不再作为正式方案继续调整。
- `Mesh_圆缓坡肩_一级`、`Mesh_圆缓坡肩_二级`：仅保留为旧实验记录，正式地块不再使用。
- `M_青绿顶面赭石侧面_圆缓坡肩试验`：仅用于回看旧方案，不再作为正式材质。
- 程序噪声纹理与相关参数：不再继续优化。

## 四、当前纹理制作要求

### 顶面

- 原型尺寸继续使用 `2048 × 2048`。
- 单次纹理覆盖范围暂以约 `4 × 4` 格为起点，在 5×5 场景中检查重复感后再调整。
- 纹理中只保留低频、大尺度变化；不画强烈中心构图。
- 不在四周主动留统一空白边，避免平铺后产生亮线。
- 明暗、青绿与浅赭的关系直接画进纹理，不依赖灯光补救。

### 侧面

- 原型尺寸继续使用 `2048 × 2048`，但有效信息保持稀疏。
- 确保一级与二级高度截取后都不会出现规则条纹。
- 顶部深赭、底部浅赭的渐变由 Shader 和贴图共同完成，避免重复压暗。

### 材质

- 普通地块以不受光照的稳定综合色为工作基线，避免方向光改变手绘颜色关系。
- Shader负责顶面与侧面分类、世界坐标取样、侧壁渐变和边缘带混合。
- Shader不负责生成随机山石、草地或水墨斑点。
- 当前 `_WorldScale = 4`，一张统一纹理约覆盖 `4 × 4` 格。
- 当前 `_EdgeWidth = 0.13`，青赭过渡带约占侧壁高度 13%。
- 当前 `_EdgeLineWidth = 0.018`，断续墨线从顶面真实边缘向内约占单格宽度 1.8%。
- 当前 `_VerticalEdgeLineWidth = 0.014`，侧壁立边墨线约占单格宽度 1.4%，并以较低不透明度出现。
- 当前 `_EdgeMaskWorldScale = 1.25`，每条一格长边缘可见数段笔触，不同朝向使用不同采样起点。
- Shader 使用遮罩的完整二维笔触轮廓控制边缘线粗细与毛边，不再固定采样遮罩中线；较低灰阶会被保留，并通过轻微横向扩张合并细小孔洞，最终只留下少量主要断口。
- `MapGenerator` 比较四方向邻居高度，并通过 `MaterialPropertyBlock` 写入 `_TopEdgeFlags`：邻居缺失或更低时显示，对方同高或更高时隐藏；因此同高度区域不会出现格子线。
- 侧壁立边只在两个外露方向相交的转角显示；连续崖壁内部的地块分界不会产生竖向墨线。
- 当前 `_SideGradientStrength = 0.72`，保留侧壁原画颜色，同时强化上深下浅的赭石层次。
- 当前 `_DefinitionTintStrength = 0`，避免地块定义色重新形成九宫格色块。
- 当前 `_TopTint` 为白色，顶面综合色直接来自手绘纹理；后续调色时再做轻微整体偏色。

## 五、后期升级方向

如果比赛制作时间允许，再将统一地面纹理升级为“每关一张地景总画布”。

升级后：

- 每个正式关卡拥有一张经过构图的地表总图；
- Shader根据地图世界坐标截取各地块对应区域；
- 同高度地块共享连续笔触，高差处像画卷被切开并抬高；
- 总图仍只负责地面气韵，山体、河道、建筑和动态状态保持模块化；
- 统一纹理方案继续作为性能兜底、测试关卡和未完成关卡的默认皮肤。

这一项属于明确延期内容，当前阶段不实施。

## 六、验证顺序

### 第一轮：3×3

1. 移除圆缓坡肩后，确认阶梯几何是否干净。
2. 检查同高度区域是否像一整片地面，而不是九块独立方砖。
3. 检查顶面、边缘带和赭石侧面的衔接是否自然。
4. 与现有山体同屏，调整地面明度、饱和度和冷暖关系。

### 第二轮：5×5

1. 检查统一纹理的重复周期是否明显。
2. 检查零级、一级、二级高差组合。
3. 加入山体、树木、村庄、直线河道和转弯河道，确认画面主次。
4. 加入一处跨级河流与瀑布，验证河道高差连续性。
5. 检查固定正交镜头下的透明排序、点击区域和缩放稳定性。

## 七、当前验收标准

- 第一眼看到的是连续山水地貌，而不是重复方块。
- 顶面青绿、边缘青赭和侧面赭石属于同一套综合色彩。
- 高差清楚但不形成沉重黑墙。
- 地面有手绘气息，但不会与山体和玩法信息争夺注意力。
- 同高度接缝不显眼；高差边缘有意可见且具有画卷断面的感觉。
- 河流只有在专用瀑布模块处跨越高差，不依赖普通地块坡肩。
