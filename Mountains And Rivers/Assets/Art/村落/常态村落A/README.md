# 常态村落 A

用于普通地块上的安居村落景片，不包含洪水、损毁或玩法逻辑。

## 分层

- `BackVillage`：远处屋舍、树竹与淡雾。
- `MainVillage`：5—7 间低矮民居、院落与弯曲土路，是主体识别层。
- `FrontVillage`：近景院墙、门、树石，中央保留进入村落的视觉通道。
- `VillageSmoke`：独立炊烟层，可在后续状态切换或性能调整时单独启停。

四层统一向 X 轴旋转 45°，按固定斜俯视相机观看；图片宽度在导入时自动归一到约一格地块。

## 生成与验收

在 Unity 菜单选择：`山河未尽 > 美术 > 创建或更新常态村落A`。

工具会生成或更新：

- `VillageTile_Normal_A.prefab`
- `D_常态村落_A.asset`
- `L_常态村落_A_3x3验证.asset`
- `Assets/Scenes/VillageTileNormalAValidation3x3.unity`

在验证场景中重点检查：主体是否完整落在中心格、前中后层有无穿插、土路入口是否清楚、炊烟是否压住屋顶、与普通地块色调是否统一。

## 图像生成提示词摘要

整体风格：青绿设色与水墨纸本质感，游戏用 2.5D 地块透明景片，固定斜俯视角，古代山村，低饱和矿物色与手绘笔触，不出现现代物件、文字、边框或完整地面底板。

主体层：5—7 间低矮灰瓦木屋围合成疏朗院落，一条弯曲土路贯穿村中，树竹、篱笆、石块少量点缀。

后层：远处少量屋舍、树竹与薄雾，轮廓轻、颜色淡、留白较多。

前层：左右两侧近景院墙、门、树木和石块，中央留出通往村内的开口，不遮挡主体。

炊烟层：三缕独立、轻薄、半透明的灰青白色炊烟，边缘柔和，无屋舍与地面元素。
