# 河流源头瀑布资源说明

## 当前已实现

- 山谷后层：两侧主体山峰与中央峡口，位于瀑布后方。
- 山谷中层：两侧内峡壁，默认位于瀑布后方并靠近峡口。
- 山谷前层：低矮近景岩壁与河口框景，位于瀑布前方。
- 常态瀑布：8 张透明帧，8 帧/秒循环播放。
- 洪水涌出：16 张透明帧，12 帧/秒播放一次，结束后停在洪水末帧。
- 洪水持续瀑布：暂未制作，后续补充为第三个循环阶段。

所有运行时帧统一为 `256 × 512`，中心裁切比例为 `1:2`。视频原片与检查图仅用于追溯和质量检查，不在运行时播放。

## Unity 资源

- `RiverSourceWaterfall.prefab`：可直接放入地块的瀑布表现预制体。
- `D_河流源头.asset`：地块系统使用的“河流源头（瀑布）”定义。
- `RiverSourceWaterfallController.cs`：逐帧播放控制器。

开始洪水结算时，对源头预制体调用：

```csharp
源头瀑布控制器.播放洪水涌出();
```

重置关卡时调用：

```csharp
源头瀑布控制器.恢复常态();
```

也可以在播放模式下打开组件右键菜单，使用“测试/播放洪水涌出”和“测试/恢复常态瀑布”检查效果。

## 重新生成

帧文件发生变化后，在 Unity 菜单执行：

`山河未尽 > 美术 > 创建或更新源头瀑布`

该工具会统一透明帧的导入设置，并重新绑定预制体中的 8 张常态帧和 16 张洪水涌出帧。

预制体内部保持 `ValleyBack → ValleyMiddle → WaterfallSprite → ValleyFront` 分离。需要调整构图时只修改对应子物体的位置和缩放，不要把山谷与瀑布合并成一张图片。
