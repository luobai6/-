# 白模地图与正交相机

## 立即试用

1. 等 Unity 编译完成后，点击菜单 **山河未尽 → 白模地图 → 创建示例场景**。
2. 双击 `Assets/Scenes/WhiteboxMapSample.unity`。这张场景有九格白模、两种高度和一格 `StraightRiver` 河道。
3. 选中“白模地图生成器”，在 Inspector 修改“地块尺寸”“每级高度”或“地图基准高度”，点击“重新生成白模”。
4. 进入 Play Mode：WASD／方向键移动，按住中键拖动画面，滚轮缩放。

示例菜单不会覆盖已存在的示例场景，也不会保存或修改当前正在编辑的场景。

## 自建关卡

在 Project 面板通过 **Create → 山河未尽 → 地块定义** 建立视觉定义，并指定可选的主要内容预制体。通过 **Create → 山河未尽 → 关卡数据** 建立地图尺寸和地块列表。把 `MapGenerator` 挂在一个空物体上，指定关卡数据与 URP 白模材质，然后点击“重新生成白模”。

地块坐标中的 Y 对应场景 Z。`高度等级 × 每级高度` 得到地块顶面 Y；“地图基准高度”应低于所有地块顶面。`StraightRiver` 等内容预制体只放在 `PrimaryContent` 下，自己的河床局部 Y 保持 0。底座上的 `WhiteboxTileColor` 会在场景重开时恢复各地块颜色。

## 当前边界

白模立方体用于验证高度、尺寸和视觉锚点。跨高度河道连接、侧壁造型、水流逻辑与完整关卡笔刷属于后续阶段。相机组件使用项目当前启用的旧输入系统；相机必须为正交模式。
